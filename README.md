# Tic Tac Toe

A browser-based Tic Tac Toe game for two players, built with HTML, CSS, and JavaScript.

## Features
- 3×3 game board
- X and O turn indicators
- Game result message
- Play Again button to restart the game

## Technologies
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.

## Project Purpose
A JavaScript game project for practicing DOM manipulation, turn management, conditional logic, and game-state updates.
